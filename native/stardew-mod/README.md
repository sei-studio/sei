# Sei companion mod for Stardew Valley

`SeiCompanion/` is a SMAPI mod (C#, net6.0, SMAPI 4.5+, Stardew Valley 1.6.14+)
that lets the Sei desktop app put an AI companion into the player's own farm.
The companion is a real NPC in the world (it walks, collides, has a speech
bubble) paired with an invisible shadow farmer that the game's own tool,
combat, fishing and inventory code accept, so it can till, water, plant,
harvest, chop, mine, fish, fight, shop and sleep like a farmhand would. The
Sei bot drives it over a loopback WebSocket (see `PROTOCOL.md`); the mod
itself has no AI in it.

Layout:

- `SeiCompanion/ModEntry.cs`: lifecycle, the game-thread queue, save hygiene.
- `SeiCompanion/Net/`: `HttpListener` server (`GET /hello`, `/ws`), sessions.
- `SeiCompanion/Body/`: the NPC + shadow pair, follow, persistence, routing.
- `SeiCompanion/Actions/`: one file per verb family (movement, tools,
  farming, combat, items, shop, fishing, interact/sleep) run as coroutines.
- `SeiCompanion/Reflex/`: per-tick reflexes (contact damage, retaliate,
  retreat, auto-eat, bedtime).
- `SeiCompanion/Observe/`: the observation JSON and the `#N` handles.
- `SeiCompanion/Chat/`: the Harmony postfix that reads in-game chat.
- `SeiCompanion/Assets/`: the default art, generated by
  `scripts/gen-stardew-placeholder-art.mjs` at the repo root.

## Building

The mod compiles against the game's own assemblies (`Stardew Valley.dll`,
`StardewModdingAPI.dll`, `MonoGame.Framework.dll`, `xTile.dll`), which ship
with the game and are not redistributable, so it can only be built on a
machine that has Stardew Valley AND SMAPI installed. The Sei repo's CI cannot
build it (the runners have no game), so the Stardew game pack is built by
hand on a developer machine with the game (`npm run build:packs:stardew`)
and uploaded with the release assets; a machine without the game gets a
clear failure from the build script instead of a wall of missing references.
`npm run check:packs` (CI) only checks that the mod sources are present.

1. Install the .NET SDK (6 or newer; the 10.x SDK builds net6.0 fine).
2. Install Stardew Valley (Steam or GOG) and SMAPI (https://smapi.io) into it.
3. From the repo root:

   ```sh
   scripts/build-stardew-mod.sh --game-path "/path/to/Stardew Valley"
   # macOS: --game-path "$HOME/Library/Application Support/Steam/steamapps/common/Stardew Valley/Contents/MacOS"
   # Windows (Git Bash): --game-path "/c/Program Files (x86)/Steam/steamapps/common/Stardew Valley"
   ```

   Without `--game-path` the script tries SMAPI's default install folders.
   `GAME_PATH` / `STARDEW_GAME_PATH` in the environment work too.

The output lands in `<repo>/assets/stardew-mod/SeiCompanion/` (DLL,
`manifest.json`, `Assets/`), which is what both the dev app and the Stardew
game pack (`node scripts/build-game-pack.mjs stardew`) read.

`dotnet build SeiCompanion/SeiCompanion.csproj -p:GamePath=...` also works on
its own; `Pathoschild.Stardew.ModBuildConfig` resolves the references from
`GamePath`.

## Installing by hand

Copy `assets/stardew-mod/SeiCompanion/` to `<game>/Mods/SeiCompanion/` and
start the game through SMAPI. On first load the mod writes `config.json`
beside the DLL with a random `Token`; the Sei app reads that file to connect.
The app's own installer does the same copy and writes the config itself.

`config.json`:

```json
{ "Port": 27431, "Token": "<random>", "AnnounceInChat": true, "ObserveHz": 2, "StartingGold": 500, "DisconnectGraceSeconds": 10 }
```

## What the companion cannot do yet

- Real tool-swing animation: the NPC hops on each swing; the effect lands
  through the shadow farmer.
- The fishing minigame: catches are rolled through the location's own fish
  table after a wait, never through the BobberBar.
- Talk to villagers, attend festivals, ride the bus, or be seen by a farmhand
  who does not have the mod (the mod refuses to spawn in that case).
- Sleep to end the day: only the host's bed ends it. The companion goes home
  at 1:50 AM and rests.
- Take damage the way a farmer does: monsters never target it, so contact
  damage is simulated by the mod's reflex loop.
