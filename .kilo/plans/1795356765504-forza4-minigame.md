# Plan: Forza 4 minigame (character vs player)

## Goal
Add a Connect Four (Forza 4) minigame inside the Sei app: character vs player, turn-based, no Minecraft involvement. Follow the established chess/Draw! pattern: authority in main, renderer is a view, IPC channels in src/shared, surface registered in GAME_CATALOG, instrumentation + continuity per AGENTS.md / CLAUDE.md.

## Decisions (already agreed with user)
- Game name: Forza 4 (Connect Four). Catalog id: `CONNECT4`.
- 1v1: character plays against the player; the character's moves are decided by the LLM (like chess picks from engine candidates).
- No Minecraft dependency; mutually exclusive with chess/Draw!/Minecraft summon per character via the same `gameLaunch.ts` cross-launch gate.
- Renderer-only UI (board + chat aside inside ChatScreen, like chess panel), full-page route optional (like Draw!) â€” decide: follow chess (panel inside ChatScreen) since it's a board beside chat.

### src/main
5. New file `src/main/connect4/connect4Service.ts` â€” authoritative game + LLM turn runner, mirroring `chessService.ts`:

   - Board: 6x7 grid; win = 4 in a row (horizontal/vertical/diagonal); draw = full board.
   - LLM decides column via a `play(column)` tool (like chess `play(move)`). Candidate generation optional (no engine vendor for Connect Four): LLM picks freely but validated against legal columns.
   - Turn kinds: `move` (AI picks column), `chat-reply`, `idle`, `game-over`.
   - `endSession` writes `CONNECT4_game_started` / `CONNECT4_game_ended` via `loadAnalytics()` (lazy import), with `duration_ms`, `character_id`, outcome, reason.
   - `endAllCONNECT4(reason)` for account switch (called from `accountSessions.ts`).
   - `shutdownCONNECT4()` for app quit.
   - Continuity OUT: `appendMemory(..., {section:'app'})` via `REMEMBER_TOOL`, `foldIfDue`, one `event:{kind:'play'}` transcript row via `playSummaryText(name, 'Forza 4', ms)`.
